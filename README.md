# AI Assistant App (MVP)

Multi-page HTML/CSS prototype with a local sequential chat demo. Gemini has been removed from this version.

## Run locally

Start the Node server:

```bash
npm start
```

Or start the Python server:

```bash
python3 python_server.py
```

Then open:

```text
http://localhost:3000
```

## Notes

- The chat now runs locally in the browser and fills responses in order.
- `.env` only keeps `PORT` for the local server.
